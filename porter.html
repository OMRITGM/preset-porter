Your filament presets, on your new printer

Switched Bambu Lab printers and your calibrated presets landed under Unsupported presets? Drop them here, pick the new printer, import the result.

Drop filament preset .json files here, or click to choose
Files are processed in your browser and never uploaded.

Where are my preset files?

  1. Windows: %APPDATA%\BambuStudio\user\<id>\filament · macOS: ~/Library/Application Support/BambuStudio/user/<id>/filament
  2. Take the .json files (ignore .info). Presets shared by filament makers work too.
  3. Import the result with File → Import → Import Configs while the new printer is selected. It appears under User presets → Custom.

What it actually changes

  1. The parent. A user preset only stores your changes and inherits the rest from a system preset that belongs to one printer family (Generic PLA @BBL P1P). On another printer that parent does not apply, so the preset is hidden. Porter swaps it for the same material's preset on the target printer.
  2. Per-nozzle values. Newer printers keep one value per nozzle type (Standard / High Flow / E3D High Flow, plus Bowden on the X2D). Your values are mapped by nozzle type; types your old printer never had inherit the system default.
  3. Nothing else. Your flow ratio, temperatures and speeds stay exactly as you calibrated them — re-run flow calibration if the hotend is very different.

Built against Bambu Studio system profiles. Tested on a real H2S: presets made for P1S, X1C and A1 that were stuck under Unsupported showed up under Custom after porting. Not affiliated with Bambu Lab. Found a preset it gets wrong? Open an issue — the source is on GitHub.
